## 实现结果

- 增加 [Python 更新器](../../scripts/deploy/sayseed-update.py)、独立 systemd service/timer、配置模板及 Nginx 维护页。按不可变摘要部署，无新版本时保持容器；首次注册已部署镜像时初始化 overlay 与部署状态。
- 备份前核验 Docker 具名卷身份及可恢复的文件类型。停机归档应用配置和完整卷，校验 tar 与 SHA256 并持久落盘；核对 SQLite 完整性、已有记录 ID 和加密密钥。
- 中断记录独立于应用目录，支持 Compose 配置被清空或候选容器尚未创建时恢复；使用旧镜像 ID，避免移动标签导致旧摘要不可用。终态先持久化再解除维护，恢复终态时不会回滚重新开放访问后的新数据。
- 清理保留最近 3 次或最近 30 天内的备份及恢复点。异常或失败记录受保护，仅清理可确认属于本仓库且无人引用的关联镜像；无法确认的旧镜像保留。
- 新增状态机单测及[真实 Docker 隔离演练](../../scripts/test-updater-docker.py)，接入现有工具测试和 CI `container` job。部署与维护操作见[服务器自动更新](../deployment.md)，Memos 复用部分保留其 MIT 声明。
- 2026-09-25 已在实际服务器安装并启用独立定时器；公网维护入口、首次检查和定时触发均实测成功。当前线上 0.1.1 已是 stable，因此没有切换镜像或重启应用。安装备份、私有配置和现场结果记录在私有运维目录。
- 本次变动为宿主机运维程序及验证工具，不改变 Web/扩展交付内容，不新增应用 changeset 或为验收发布虚假版本。
