# Sayseed

用自然英文表达自己的想法，在真实交流中学会新表达。

Sayseed 是个人自托管的 Chrome 扩展和联网复习网站。中文直接写在 X 输入框，助手结合相关文字生成英文；阅读网页时，可以划选表达、查看语境义，再把原句一起保存到词库。

## 功能

- X 独立发帖、详情回复、弹窗回复、引用转帖四个入口。
- 一次点击开始流式翻译，支持中文继续修改、英文编辑、复制、回填与撤销。
- 上下文预览和补充；回复只读取直接回复对象，引用只读取被引用帖子，独立发帖无上文。
- 翻译和解释浮窗可拖动；译文解释优先显示在翻译窗右侧。
- 普通网页划词：选中后出现解释按钮，点击才请求模型，保存表达、原句、解释和来源。
- 网页设置多个供应商：OpenAI Responses、OpenAI Chat Completions、Anthropic、Google；密钥只保存在服务端。
- 词库搜索、编辑、暂停、删除与数据导出。
- 后台模型使用记录：查看翻译、解释和模型测试的时间、结果、耗时、推理设置与 token 用量，可按用途、状态和模型筛选。
- FSRS 原句理解卡：先回想再翻面，四档评分，复习进度跨设备同步。
- 适配 iPhone 的联网 PWA。首版不提供离线评分、推送、挖空题或自动发帖。

## 本地运行

需要 Node.js 22.12+ 和 pnpm 12.4.1，推荐使用 `.node-version` 中的固定版本，与 CI 和镜像一致。所有命令均从项目根目录执行。

```bash
pnpm install
cp .env.example apps/web/.env.local
```

编辑 `apps/web/.env.local`，设置自己的 `SAYSEED_PASSWORD`。未配置密码时服务不会开放数据或模型接口。模型的 API Key 在启动后的「设置」页面填写，不需要写进代码。

```bash
pnpm dev
```

访问 `http://localhost:3000`，用配置的密码登录。在设置页添加供应商、模型 ID，设置默认模型并测试连接。翻译只发送文字上下文，不要求模型具备图片能力。

添加或编辑模型时，选择已保存的供应商，点击「获取模型列表」，即可搜索名称或 ID 并选择。OpenAI Responses、OpenAI Chat Completions、Anthropic 和 Google 都支持此流程，查询使用供应商中保存的地址与密钥。列表明确声明的图片能力、上下文窗口、输入上限和最大输出会自动填入；未返回的能力显示未知，不根据模型名称猜测。图片选项仍可手动覆盖。已有模型也可以在编辑时重新获取列表，同步当前模型的能力后保存。第三方服务未实现列表接口时，仍可手动填写模型 ID。

翻译系统提示词完整保留用户确认的语境、语气分寸、忠实度、自然表达和输出前检查要求，源文件为 `apps/web/src/server/prompts.ts`；输入模板按每次草稿和上下文填充。用户补充意图与网页参考材料分开传入，必要澄清使用应用约定的 `CLARIFY:` 前缀。

AI SDK 不要求传入上下文长度；这些数值是服务方声明的容量信息，不会自动作为本次请求的输出额度。输入上限与总上下文窗口分别显示。更换供应商的地址、协议或密钥会清除旧能力及读图开关，需要重新获取或确认。

模型列表明确返回推理强度档位时，设置页会提供相应选择，默认「跟随服务商」。DeepSeek 官方 HTTPS 接口的已声明推理模型还提供「关闭」，按官方协议发送 `none`；已有模型需重新获取模型列表以更新选项。其他兼容接口只有明确返回 `none` 时才显示关闭，不把最低档位当作关闭。支持 DeepSeek 的 `effort.supported_levels` / `default_level` 和 Anthropic 的各档位声明；只有「支持思考」而没有档位时不提供强度选择。服务端只接受实际查询过的档位，翻译、解释和连接测试沿用保存的选择。重新查询撤销了某个档位，或修改供应商配置时，失效配置自动恢复为跟随服务商。

模型使用记录支持按需展开「查看上下文」：查看调用时完整的系统提示词、输入消息、请求选项、原始输出，以及供应商实际返回的思考内容（若有）。失败或取消时保留截至结束时收到的输出。内容存入本机数据库，不记录 API 密钥或鉴权请求头。历史记录中已保存的图片仍可查看；旧记录未保存的上下文无法回补；服务方未返回的用量显示「未知」。删除模型或供应商后仍保留历史记录。

推理强度控制模型的推理投入；是否返回可读思考文本取决于接口。Responses 接口会同时兼容 SDK 的思考摘要与 DeepSeek 等服务返回的 `reasoning_text` 正文；只提取思考文本，不保存完整原始响应或响应头。记录为空表示没有记录到这段内容，不能据此判断模型没有推理。修复前漏记的历史内容无法回补。

网页和扩展登录有效期均为 30 天，活跃使用时每天最多续期一次，续期后再有效 30 天；后台挂着不保活。已过期的登录需要重新登录，退出后旧网页会话不能继续续签。

## 安装扩展

```bash
pnpm --filter @sayseed/extension build
```

1. 打开 Chrome 扩展管理页面，启用开发者模式。
2. 选择「加载已解压的扩展程序」，选择 `apps/extension/.output/chrome-mv3`。
3. 扩展在安装或升级时统一声明 HTTP/HTTPS 网站访问权限，浏览器可能在此时要求确认。点击扩展图标，直接在小弹窗中填写地址（例如 `http://localhost:3000`）和密码，点击「连接并登录」即可，无需另开标签页，使用中不再单独申请服务器权限。
4. 刷新 X 页面，在发帖或回复输入框旁点击助手按钮。主帖回复框收起时不显示助手，展开后显示在「回复」右侧并垂直居中。
5. 在扩展弹窗中启用网页划词，然后刷新要阅读的网页；该开关不再触发权限申请。

划词针对网页中可选中的英文文字；Chrome 内部页面、浏览器内置 PDF 阅读器和图片内的文字不属于首版范围。X 翻译仅使用帖子文字，不发送或读取图片内容。直接回复对象或引用帖子读取失败时会提示补充；不再因没有更早回复链而提示缺失。

开发扩展可运行 `pnpm dev:extension`。扩展和网页必须指向同一个服务端才能同步词库。

## iPhone 复习

服务器配置 HTTPS 后，在 iPhone Safari 打开网站并登录，通过「分享 → 添加到主屏幕」安装。复习需要网络：评分成功保存后才切换卡片；请求失败时保留当前卡片以便重试。

四档评分含义：没想起来（包括看答案后才认出）、费劲但正确、正常想起、轻松想起。收藏不会计为一次成功复习，首次评分才写入复习记录。FSRS 负责下次复习时间，日常翻卡无需调用模型。

## 自托管

```bash
cp .env.example .env
```

设置 `.env` 中的 `SAYSEED_PASSWORD` 和外部访问地址 `SAYSEED_PUBLIC_URL` 后：

```bash
docker compose up -d --build
```

容器默认只绑定服务器的 `127.0.0.1:3000`。使用自己的 HTTPS 反向代理将域名转发至该端口，并关闭流式响应的代理缓冲。PWA 和生产登录需要 HTTPS。扩展中填写同一个外部地址。

SQLite 数据库和加密密钥位于 `sayseed-data` 命名卷。请备份整个数据目录，并保留部署密码；仅复制数据库而丢失密钥将无法解密模型凭据。迁移服务器时，停机复制完整数据卷，再以相同数据目录启动。网页 JSON 导出用于保存学习数据，不包含模型凭据，也不是完整实例备份。

## 检查

```bash
pnpm typecheck
pnpm test
pnpm build
```

自动化测试不调用收费模型接口。真实翻译自然度和不同供应商兼容性需要在设置 API Key 后用实际材料验证。X 页面结构可能变化，扩展的上下文提取和输入框绑定有针对性测试，但仍应在发布前验证四个真实入口。

本地协议模拟器和隔离联调步骤见 [验证说明](docs/testing.md)。

后续迭代的文档入口与记录约定见 [开发与迭代文档](docs/README.md)；需求、修复和关键决定使用独立 Task 沉淀，按需检索历史。

GitHub Actions 复用上述检查，并自动运行隔离 HTTP 联调和容器验证。版本 PR、服务端镜像和独立扩展 ZIP 的设置及发布规则见 [CI 与版本发布](docs/release.md)。

## 项目结构

```text
apps/extension   Chrome MV3 扩展（WXT + React）
apps/web         网页、PWA 和服务端 API（Next.js）
packages/shared  请求校验、共享类型和评分标签
docs             需求与接口说明
```

模型调用使用 AI SDK，数据通过 Drizzle 存入 SQLite，复习采用 ts-fsrs 默认参数。服务端只为当前明确请求处理上下文；收藏以当时确认的句子版本保存，后续改稿不会自动改写词卡。
